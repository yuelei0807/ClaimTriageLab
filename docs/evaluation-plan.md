# Evaluation plan

Task 00 verifies reproducibility only. Task 03 will define fixed holdout metrics: precision, recall, PR-AUC, recall at review capacity, calibration/Brier score, false referrals, missed referrals, latency, and meaningful slice checks. Task 04 adds citation accuracy and unsupported-claim tests. Task 06 adds pause/restart/resume tests.

An LLM judge may later score writing quality, but it will not determine the principal release gate.
